# Open Source Philosophy

Menerio is built in public as an open system for connecting applications through events.

The goal is not to create another isolated SaaS product, but to establish a shared infrastructure layer for personal data and application interoperability.

## Principles

### Transparency
Core logic, architecture, and decisions are developed openly.

### Ownership
Each application remains the owner of its data. Menerio does not take control of data, it coordinates it.

### Composability
The system is designed so that independent applications can connect, exchange events, and evolve without tight coupling.

### Practicality
The focus is on building systems that work in real-world scenarios, not theoretical architectures.

## Why AGPL-3.0

The AGPL license ensures that:
- Improvements to the core system remain open
- The infrastructure cannot be closed off and resold as a proprietary backend
- The ecosystem stays accessible to builders

## Status

Menerio is in an early public stage.

Expect rapid iteration, breaking changes, and evolving architecture.
